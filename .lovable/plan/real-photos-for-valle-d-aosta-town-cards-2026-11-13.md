# Real photos for Valle d'Aosta town cards

All 15 town cards (3 featured: Aosta, Courmayeur, Cogne; 12 in More Towns) point to photos that don't exist, so none show today.

## Steps
1. Search Wikimedia Commons (free, reusable licences, CC BY / CC BY-SA / public domain) for one good landscape photo per town. Fall back to Unsplash/Pexels if Commons has nothing suitable.
2. Download each, resize to ~1600px wide JPG, save locally under the region's image folder using the file names the cards already expect (e.g. `aosta-featured.jpg`, `morgex.jpg`). No database changes needed when names match.
3. Add a small credit (photographer + licence) to each card's existing credit field where the licence requires attribution.
4. Run the image checker and confirm all cards show photos in the preview.
5. Report back with a list of any towns where no decent free photo turned up, so you can supply those.
